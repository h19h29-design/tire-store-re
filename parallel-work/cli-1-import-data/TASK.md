# CLI 1: Import / Data Foundation

## 목표

숫자와 규격이 정확해야 나머지 화면 수치가 맞습니다. 이 작업은 프로젝트의 기준 데이터와 import 정확도를 담당합니다.

## 담당 범위

- 금액 입력/저장 스케일 규칙 정리
- `재고관리.xlsx`의 `고객등록` 시트 import 추가
- `재고관리.xlsx` 안의 일자별 판매 관련 데이터도 DB 반영 검토
- 규격 문자열 정규화
- 일자별 판매량 불일치 원인 분석 및 보정

## 우선 파일

- `src-tauri/src/commands.rs`
- `src-tauri/migrations/*.sql`
- `src/lib/normalize.ts`
- `src/lib/types.ts`

## 구현 기준

- 금액 입력 `300`은 저장 시 `300000`원으로 반영
- 기존 DB 금액은 마이그레이션 또는 import 시점에 통일
- 규격 표시는 `255 45 19`
- 검색용 정규화 키는 별도로 생성
- 판매이력 import 후 일자별 판매수량 검증 쿼리 제공

## 산출물

- 금액 스케일 유틸
- 규격 정규화 유틸
- 고객등록 시트 import
- 판매량 검증용 쿼리 또는 테스트
