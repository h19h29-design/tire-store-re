# CLI 4: Customers / Settings

## 목표

고객 화면을 차량 중심으로 바꾸고, 운영 설정을 실제 매장 기준으로 손봅니다.

## 담당 범위

- 고객/차량 화면을 차량번호 중심으로 재설계
- 판매건수 대신 판매수량, 비고, 판매금액, 현금/카드 구분, 얼라이먼트 구분 추가
- 키로수 입력란 추가
- 저재고 임계값 설정 추가
- 표시 옵션/운영 옵션 연결
- 필요 시 일일 지출 입력 보조 화면 또는 설정 연결

## 우선 파일

- `src/features/customers/*`
- `src/features/settings/*`
- `src/lib/types.ts`
- 필요 시 `src/features/sales/*`

## 구현 기준

- 목록 첫 기준은 차량번호
- 고객명은 보조 정보로 유지한다
- 판매 수량/금액/결제수단/비고/얼라이먼트 금액 확인 가능
- 키로수는 판매 저장 시 함께 기록 가능해야 함
- 저재고 임계값은 설정에서 수정 가능해야 함

## 산출물

- 차량 중심 고객화면
- 키로수 저장 필드
- 설정 화면 확장
