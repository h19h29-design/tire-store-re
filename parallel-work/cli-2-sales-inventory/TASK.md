# CLI 2: Sales / Inventory UX

## 목표

매장에서 가장 자주 쓰는 `빠른판매`와 `재고조회/입력`을 실제 사용 속도 중심으로 개선합니다.

## 담당 범위

- 빠른판매 금액 입력을 천원 단위 입력으로 변경
- 얼라이먼트 금액 기본 칸 추가
- 추가작업명은 선택 입력으로 유지
- 추가작업 미입력이어도 판매저장 가능 유지/검증
- 재고조회에서 판매가 제거
- 상품검색 토큰 검색 강화
- 재고조회/입력에서 저재고 표시 연동

## 우선 파일

- `src/features/sales/*`
- `src/features/inventory/*`
- `src/App.css`
- 필요 시 `src/lib/types.ts`

## 구현 기준

- `145`, `145 13`, `145 r 13` 검색 모두 동작
- 판매표에 `얼라이먼트 금액` 기본 입력란 존재
- 판매 저장 시 작업명 없이도 저장 가능
- 재고조회 표에서는 판매가 열 제거
- 저재고는 설정값 이하일 때 표시

## 산출물

- 빠른판매 개편
- 검색 토큰 로직
- 재고입력/조회 개편
