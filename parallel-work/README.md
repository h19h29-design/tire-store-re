## 이번 라운드 핵심 요구사항

1. 빠른판매에서 단가 입력 없이 판매 가능
2. 타이어 없이 `작업명 + 추가 작업비`만으로 저장 가능
3. 재고조회에서 총 재고 수량 확인 가능
4. 카드수수료는 기본 3%, 네이버 체크 시 5%
5. 일간 타이어 수익 = 총 판매가격 - 타이어 자산가 - 카드수수료 - 일일지출
6. 고객/차량 화면은 차량번호 중심, 영문 `imported ...` 메모 숨김
7. 최근 판매내역은 `전표번호` 대신 `차량번호 + 고객` 표시
8. 신규 품목 / 신규 규격 등록 가능
9. 브랜드별 또는 품목별 할인율 적용
10. 1080p 기준으로 빠른판매가 한 화면에 최대한 들어오도록 압축
11. `재고관리_연동.xlsx`의 `고객등록` 시트 과거 판매를 DB에 함께 import

## CLI 역할 분담

- `cli-1-import-data`
  - 엑셀 import
  - 고객등록 시트 과거 판매
  - 판매량 정합성
  - 수수료/할인 관련 DB 컬럼 보정

- `cli-2-sales-inventory`
  - 빠른판매
  - 재고조회 / 재고입력
  - 신규 품목 등록
  - 1080p UI 압축

- `cli-3-dashboard-analytics`
  - 일간/월간/연간 수익 계산
  - 카드수수료 반영
  - 최근 판매내역 표
  - 총 재고 / 저재고 / 검증

- `cli-4-customers-settings`
  - 고객/차량 화면
  - 영문 imported 메모 숨김
  - 브랜드/품목 할인율 설정
  - `데이터 보정 실행` 설명
  - 인코딩 꼬인 설정 화면 정리

## 실행 순서

1. `cli-1-import-data`
2. `cli-2-sales-inventory` + `cli-4-customers-settings`
3. `cli-3-dashboard-analytics`
4. 마지막 통합 빌드와 설치 파일 배포

## 공통 규칙

- 금액 입력 `300`은 내부 저장 `300000원`
- 규격 표시는 `255 45 19`
- 검색은 `145`, `145 13`, `145 r 13`, `2554519` 모두 인식
- 빠른판매는 1080p 기준으로 페이지 스크롤을 최소화
- 최종 산출물은 설치 파일과 업데이트 내용 TXT까지 포함
