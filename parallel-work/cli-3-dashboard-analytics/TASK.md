# CLI 3: Dashboard / Analytics

## 목표

대시보드 수치를 실제 매장 운영 기준으로 보이게 만듭니다.

## 담당 범위

- 오늘 판매 요약 유지
- 일일 수익 표시
- 일일 지출 입력/조회 구조 추가
- 총 재고 수량 표시
- 저재고 경고 표시
- 날짜/월/연도별 판매내역 검증
- 규격별 판매량/브랜드별 판매량 정확성 점검

## 우선 파일

- `src/features/dashboard/*`
- 필요 시 `src/lib/types.ts`
- 필요 시 `src/features/settings/*`

## 구현 기준

- 수익 계산식은 `타이어 매출 - 타이어 원가 + 정비/얼라이먼트 수익 - 일일지출`
- 판매량은 `sale_lines.quantity` 기준으로 검증
- 작업비/얼라이먼트는 일일 수익 계산에 포함
- 총 재고 수량은 품목 수가 아니라 전체 개수 합계
- 저재고는 설정 임계값과 연결
- `타이어가격`은 우선 `items.default_cost_price` 또는 해당 판매시점 원가 기준으로 계산

## 산출물

- 대시보드 카드/표/분석 개편
- 일일 지출 입력 모델 또는 화면
- 판매량 검증 결과
- 총 재고 / 저재고 표기
