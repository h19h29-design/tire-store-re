Tire Store 1.61 변경 요약

1. 업데이트 탭 분리
- 설정 화면 안에 있던 업데이트 확인 영역을 별도 업데이트 탭으로 분리했습니다.
- 실행 중인 Tauri 앱의 실제 버전을 읽어서 서버 업데이트와 비교합니다.
- 자동 업데이트 검증이 실패해도 서버에 새 버전이 있으면 설치 파일 다운로드 버튼을 사용할 수 있게 했습니다.

2. Litire 서버 업데이트 업로드 개선
- 서버 관리자 화면에서 업데이트 ZIP 파일을 바로 업로드할 수 있게 했습니다.
- ZIP 안의 설치 파일(.exe/.msi)과 대응 .sig 파일을 자동으로 추출합니다.
- 설치 파일명에서 버전을 자동 감지합니다.

3. 라이선스 임시 제거
- 배포 전 단계에 맞춰 앱 화면을 막던 라이선스 차단을 제거했습니다.
- 설정 화면의 라이선스/결제 테스트 섹션을 제거했습니다.

4. 버전 표시 정책
- 내부 배포 버전은 semver 호환을 위해 1.61.0으로 유지합니다.
- 앱 화면에는 1.61처럼 마지막 .0을 숨겨 표시합니다.
- 이후 수정 배포는 1.62.0, 1.63.0처럼 올리고 화면에는 1.62, 1.63으로 표시합니다.

5. 검증
- npm run release:check-version 통과
- npm run build 통과
- npm run lint 통과
- cargo test 통과
- npm run tauri:build는 설치파일 생성 후 updater 서명 private key 부재로 마지막 서명 단계에서 실패
