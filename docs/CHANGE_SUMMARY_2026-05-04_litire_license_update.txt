Tire Store 1.6.0 변경 요약

1. Litire 라이선스 서버 연동
- 기본 라이선스 서버 주소를 https://litire.h19h19.synology.me 로 설정했습니다.
- 발급받은 아이디/이메일과 라이선스 키로 앱을 활성화할 수 있게 했습니다.
- 기기 ID를 자동 발급하고 서버에 기기 활성화를 등록합니다.
- 라이선스가 없거나 만료/중지 상태이면 설정 화면 외 기능을 차단합니다.
- 서버 연결 실패 시 최근 정상 확인된 라이선스는 유예 상태로 사용할 수 있게 했습니다.

2. 라이선스/업데이트 서버
- server/license-billing-server.mjs를 Litire용 라이선스/업데이트 서버로 정리했습니다.
- /admin 화면에서 라이선스 발급과 업데이트 등록을 할 수 있습니다.
- /licenses/activate 와 /licenses/check 로 앱 라이선스를 검증합니다.
- /updates/... 와 /tauri-updates/... 로 일반 업데이트 확인과 Tauri 자동 업데이트 manifest를 제공합니다.

3. Tauri 자동 업데이트
- @tauri-apps/plugin-updater 와 @tauri-apps/plugin-process 를 추가했습니다.
- 앱 updater endpoint를 https://litire.h19h19.synology.me/tauri-updates/stable/windows/x86_64/{{current_version}} 로 설정했습니다.
- Tire Store 전용 updater public key를 앱에 넣었습니다.
- 서명된 NSIS/MSI 업데이트 artifact 생성을 확인했습니다.

4. TA91 / TA91+ 검색 분리
- 패턴명 정규화에서 + 문자를 보존하도록 변경했습니다.
- TA91, TA91+ 같은 패턴 코드 검색은 부분일치가 아니라 패턴 정확 일치로 처리합니다.
- 신규/수정 품목의 normalized_pattern과 alias 저장도 + 보존 방식으로 변경했습니다.

5. 검증
- npm run build 통과
- npm run lint 통과
- cargo test 21개 통과
- Litire 서버 스모크 테스트 통과
- TA91 / TA91+ 정규화 분리 확인
- npm run tauri:build 통과
- release app.exe 10초 이상 실행 유지 확인
