Tire Store 1.6.1 변경 요약

1. 판매 수정 추가작업명 보정
- 대시보드 판매내역에서 수정 진입 시 추가작업명이 used로 표시되는 문제를 수정했습니다.
- 기존 가져오기 데이터의 used 작업 라인은 수정 화면에서 중고로 표시합니다.
- service 같은 내부 코드성 작업명은 수정 화면의 추가작업명에 그대로 노출하지 않도록 정리했습니다.

2. 일일 지출 추가 버튼
- 대시보드 일일 지출 입력에 지출 추가 버튼을 추가했습니다.
- 지출 추가 모드에서는 기존 날짜 지출에 입력 금액을 더하고, 비고는 뒤에 이어 붙입니다.
- 기존 지출 수정 모드로 다시 전환할 수 있게 했습니다.

3. 일간순이익 작업비 계산 보정
- 순이익 계산 시 service 타입뿐 아니라 used 등 비타이어 작업 라인도 작업비로 합산하도록 수정했습니다.
- 순이익 기준은 타이어 매출 + 작업비 - 할인적용 원가 - 카드수수료 - 일일 지출입니다.

4. 검증
- npm run build 통과
- npm run lint 통과
- cargo test 통과
- 라이선스/업데이트 서버 스모크 테스트 통과
- 서버 업로드용 NSIS 설치파일과 sig 파일 생성
