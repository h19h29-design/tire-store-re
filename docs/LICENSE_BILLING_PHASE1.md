# Tire Store 라이선스/결제 1차 메모

구현 범위
- 테스트용 라이선스/결제 서버 추가
- 설정 화면에 라이선스 서버, 매장 코드, 활성화 코드, 테스트 플랜 생성 UI 추가
- 앱 시작 시 라이선스 상태 확인 후 만료/미활성 시 설정 화면 외 기능 차단
- 월간 128,000원, 연간 348,000원 테스트 플랜 반영

실행 방법
```powershell
cd C:\gpt\01project\tire-store-re
npm run billing:api
```

앱에서 테스트 순서
1. 설정 > 라이선스/결제 테스트
2. 서버 주소 `http://127.0.0.1:4175` 확인
3. 매장명/대표자명/연락처 입력 후 `테스트 결제 / 코드 생성`
4. 매장 코드/활성화 코드 자동 채움 확인
5. `라이선스 활성화`
6. 상태 확인 버튼으로 만료일과 플랜 확인

다음 구현 단계

- requestBillingAuth 리다이렉트 페이지 추가

- 웹훅 저장
- 월 자동결제 스케줄러 연결
- 관리자용 라이선스 해제/연장 페이지 추가
