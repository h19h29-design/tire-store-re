Tire Store 1.5.0 변경 요약

버전
- 앱 버전을 1.5.0으로 올렸습니다.

대시보드
- 일일 지출내역 메모 끝에 붙던 ? 문자를 제거했습니다.
- 판매일보 우측 지출내역 박스에서 카드수수료를 제외한 실제 지출만 읽어오도록 보정했습니다.
- 판매일보의 지출 금액은 천원 단위 입력값을 원 단위로 변환해 저장하도록 정리했습니다.
- 저재고 품목, 운영 현황, 판매량 정합성 검증 섹션은 정리했고 판매 내역을 상단에서 더 바로 볼 수 있게 조정했습니다.

고객/차량
- 차량번호, 전화번호, 이름 첫 글자부터 검색되도록 검색 기준을 완화했습니다.
- 고객 수정 버튼이 실제 수정 패널로 이동하도록 보정했습니다.
- 과거 재고관리 엑셀에서 잘못 들어온 연락처와 주행거리 데이터를 복구하는 보정 로직을 추가했습니다.
- 연락처 앞자리 0이 빠진 데이터는 010-0000-0000 형식으로 다시 맞춥니다.
- 비정상적으로 큰 주행거리는 자동으로 정리합니다.

판매
- 판매 화면에서 기존 고객 조회가 더 빠르고 넓게 검색되도록 차량번호, 전화번호, 이름, 차종, 브랜드까지 포함해 보강했습니다.
- 과거 판매 수정 시 연결이 끊긴 타이어 품목이 있어도 스냅샷 기준으로 수정 화면을 열 수 있게 보정했습니다.

재고/초기가져오기
- 판매일보와 재고관리 엑셀을 바탕으로 런타임 시작 시 누락된 고객, 연락처, 주행거리, 지출 데이터를 보정합니다.
- 번들 DB에도 최신 데이터와 보정 결과를 포함했습니다.

DB/런타임 보정
- 앱 시작 시 daily_expenses.note에 ?가 남아 있으면 자동으로 원으로 바꿉니다.
- 앱 시작 시 과거 잘못 이관된 고객 연락처, 주행거리, 재고관리 시트 기반 고객 데이터를 함께 점검합니다.

검증
- npm run lint 통과
- npm run build 통과
- cargo test 21개 통과
- npm run tauri:build 통과
