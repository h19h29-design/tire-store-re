# Tire Store 라이선스/결제 테스트 가이드

현재 상태

- 라이선스/업데이트 서버가 추가되어 있습니다.
- 앱 설정 화면에서 테스트 라이선스를 만들고 활성화할 수 있습니다.
- 기본 동작은 개발용 테스트 플로우 기준입니다.
- 토스페이먼츠 실결제는 사업자/상점 키 발급 후 연결하면 됩니다.

실행 순서

1. 프로젝트 폴더에서 라이선스 서버 실행

```powershell
cd C:\gpt\01project\tire-store-re
npm run billing:api
```

2. 다른 터미널에서 앱 실행

```powershell
cd C:\gpt\01project\tire-store-re
npm run tauri:dev
```

3. 앱에서 `설정 > 라이선스 / 결제 테스트`로 이동
4. 서버 주소가 `http://127.0.0.1:3100` 또는 운영 서버 주소인지 확인
5. 매장명 / 대표자명 / 연락처 / 플랜 입력
6. `결제 페이지 / 코드 생성` 버튼 클릭
7. 테스트 라이선스가 생성되면 앱으로 돌아와 `라이선스 활성화`
8. `라이선스 상태 확인`으로 만료일과 플랜 확인

검증 완료 항목

- `/health` 응답 확인
- 테스트 라이선스 생성 확인
- 라이선스 활성화 확인
- 만료/중지 상태 차단 확인
- 업데이트 release 등록 확인
- Tauri updater manifest 응답 확인
- `npm run build` 통과
- `npm run lint` 통과
- `npm run tauri:build` 통과
- 릴리즈 `app.exe` 10초 이상 실행 유지 확인

현재 과금 정책

- 월간: 초기 세팅비 99,000원 + 월 29,000원
- 연간: 348,000원 / 초기 세팅비 면제
